# Debug Android

Use esta skill para investigar erros, crashes, comportamento incorreto ou falhas de build.

## Processo

1. Reproduza o problema quando possível.
2. Leia a mensagem de erro completa.
3. Identifique arquivo e linha relacionados.
4. Analise o código ao redor.
5. Procure a causa raiz.
6. Evite alterar código não relacionado.
7. Faça a menor correção possível.
8. Execute novamente o comando que falhou.
9. Confirme que o problema original foi resolvido.

## Build

Quando houver erro de compilação:

1. reproduza o erro;
2. corrija a primeira causa relevante;
3. compile novamente;
4. continue apenas se novos erros permanecerem.

Não faça várias alterações especulativas ao mesmo tempo.
