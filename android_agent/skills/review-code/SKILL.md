# Review Android Code

Use esta skill ao revisar código Android existente.

## Processo

Analise nesta ordem:

1. bugs e problemas funcionais;
2. lifecycle;
3. concorrência;
4. gerenciamento de estado;
5. arquitetura;
6. testabilidade;
7. legibilidade;
8. performance.

## Resultado

Para cada problema encontrado:

- explique o problema;
- indique impacto;
- mostre a correção sugerida.

Não proponha refatorações apenas por preferência estilística.

Priorize problemas que realmente afetam o código.
