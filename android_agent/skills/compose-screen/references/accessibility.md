# Acessibilidade no Compose

- Forneça descrição significativa para controles sem rótulo visual; use descrição nula em imagens
  puramente decorativas.
- Preserve semântica, ordem de foco e suporte a leitores de tela.
- Use tamanho de toque adequado mesmo quando o elemento visual for menor.
- Não comunique estado somente por cor.
- Use recursos de string para texto apresentado ao usuário.
- Verifique contraste, escalonamento de fonte e layout com conteúdo maior.
